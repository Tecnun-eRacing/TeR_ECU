# TeR_ECU
La versión V2 de la ECU busca implementar varias mejoras:
- Puerto de Debugging Unificado
- MCU integrado en PCB
- SD para logging (Formato Can utlis)
- Relé Safety line
- Salidas IO para DRS, pwm REFRI y LEDS Spain
- Leds indicadores
- Mejoras en la protección del CAN
- USB-C
- Acceso al can mediante SL-CAN (https://github.com/DanielAdelodun/stm32-slcan-bridge)
- Entradas ADC para sensor de freno
